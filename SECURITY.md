# Security Policy

## Reporting Security Issues

We take the security of this project seriously. If you discover a vulnerability or security issue, please notify us privately.

Please send an email detailing the issue to mehanshbarthwal@gmail.com.

Please include:
* Description of the issue
* Steps to reproduce the problem
* Affected tools or components
* Potential impact

## Disclosure Policy

* We will acknowledge receipt of your report within 48 hours.
* We will investigate the issue and provide regular updates on our progress.
* Once a fix is verified, a patch will be published promptly.
* Public disclosure occurs only after a resolution is released to safeguard users.
